# Project Sentinel Mini

This repository serves as a backup archive for **Project Sentinel Mini**.

It exists primarily to preserve versions of the project's source code, device firmware, and related scripts. The repository acts as a reference point for the development history and ensures that the project's components remain safely stored and accessible.

Project Sentinel Mini is an ongoing initiative focused on building a compact and reliable system for device monitoring and control.

The contents of this repository may evolve as the project continues to develop.
